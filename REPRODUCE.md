# 🔁 Reproducibility package

**Research only. Not financial advice.** Times in this repository are in **MST**. Pump-day candles are **UTC** daily closes.

A third party should be able to re-run the pump-day test and to re-read the major holdings and evidence links from public pages, and get the same numbers the reports already publish. This page lists the public endpoints and the scripts that do that. It does not include private worksheets, local machine paths, or unpublished drafts.

The scoring rules themselves are in [METHODOLOGY.md](METHODOLOGY.md).

---

## Pump-day test

Pre-registered rule, effective 16 Nov 2026: a **UTC** daily close at least **10%** above the close **5** calendar days earlier. The price-source hierarchy is in the methodology page.

From the repository root:

```
python3 scripts/pump_day_test.py --exchange mexc --pair ZANOUSDT --start 2025-11-16 --end 2026-11-16
python3 scripts/pump_day_test.py --exchange kraken --pair SHXUSD --start 2026-01-01 --end 2026-11-16
python3 scripts/pump_day_test.py --exchange gate --pair BTC_USDT --start 2025-11-16 --end 2026-11-16
python3 scripts/pump_day_test.py --csv daily_closes.csv --date-col date --close-col close
```

`--csv` reads UTC daily closes you already have, and makes no network call. `--json` or `--out FILE` writes machine-readable output.

The script talks only to public HTTP APIs. It does not score a token and it does not write back into a report.

## Public market and data APIs

Used for prices, fees, and market snapshots. Exact query times are stored on each report (`price_source`, `retrieval.source_read_dates`, and the Sources section) and in the companion JSON.

| Source | What it is used for | Public endpoint |
|---|---|---|
| Gate.io | Preferred daily closes when Binance is unreachable | `https://api.gateio.ws/api/v4/spot/candlesticks` |
| MEXC | Daily closes | `https://api.mexc.com/api/v3/klines` |
| KuCoin | Daily closes | `https://api.kucoin.com/api/v1/market/candles` |
| Kraken | Daily closes | `https://api.kraken.com/0/public/OHLC` |
| Binance | Daily closes when reachable | `https://api.binance.com/api/v3/klines` (may return HTTP 451 in some regions) |
| CoinGecko | Market snapshots; daily closes as a last resort | `https://api.coingecko.com/api/v3/` |
| DefiLlama | Fees, revenue, TVL, and (when present) holders revenue | `https://api.llama.fi/` and `https://defillama.com/` |

## Public explorers and RPCs

Holdings, transfers, contract reads, and evidence links come from public explorers and public RPC endpoints. A report names the endpoint it used and the read time. Typical sources:

| Source | Typical use | Public entry point |
|---|---|---|
| Etherscan v2 API | Ethereum and other EVM chains it covers (transfers, logs, contract source) | `https://api.etherscan.io/v2/api` |
| Ethereum public RPC | `balanceOf`, `totalSupply`, `wards`, and similar reads | `https://ethereum.publicnode.com` and other public RPC lists |
| TronGrid / Tronscan | TRON transfers, balances, and contract reads | `https://api.trongrid.io/` · `https://tronscan.org/` |
| Solscan | Solana accounts, tokens, and transactions | `https://solscan.io/` · `https://public-api.solscan.io/` |
| Other public explorers | Address and transaction evidence already linked in the reports | Basescan, Arbiscan, Polygonscan, Bscscan, Stellar Expert, Subscan, HashScan, and others named on the page |
| Arkham | Entity and exchange labels, always Tier B | `https://intel.arkm.com/explorer/address/<address>` (signed-in reads are labelled as such; the address pages themselves are public) |

Explorer URLs already published in a report are the primary record for that claim. Click through.

## Public addresses examined

[data/public-addresses.json](data/public-addresses.json) lists every address extracted from a public evidence link or explorer URL already published in `banking-rails/<TICKER>.md`. It is regenerated by `python3 scripts/build_data_layer.py`.

No private address worksheet is published. If an address is not in a published report, it is not in this file.

## Companion JSON and hashes

Each published report has `data/reports/<TICKER>.json`. The `source_markdown.sha256` field is the SHA-256 of the published Markdown (UTF-8 bytes). To check one file:

```
python3 - <<'PY'
from pathlib import Path
import hashlib, json
ticker = "SKY"
raw = Path(f"banking-rails/{ticker}.md").read_bytes()
digest = hashlib.sha256(raw).hexdigest()
rec = json.loads(Path(f"data/reports/{ticker}.json").read_text())
assert rec["source_markdown"]["sha256"] == digest
print("ok", ticker, digest)
PY
```

Or run `python3 scripts/validate_reports.py`, which checks every published report.
